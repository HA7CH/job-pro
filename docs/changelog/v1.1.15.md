# v1.1.15 更新说明

> 发布日期：2026-07-11

## 🎉 这次更新做了什么？

修好了 DeepSeek、月之暗面（Kimi）、阶跃星辰、旷视、寒武纪、吉利、银河通用这 7 家公司的搜索——以前搜关键词会漏掉大量真实在招的岗位，现在能搜到全部，而且 `detail` 命令终于能看这几家的完整 JD 了。

## 🐛 修复的问题

**搜索漏岗（最严重）**
- 之前的表现：`job-pro deepseek search "前端"` 返回 0 条，让人以为 DeepSeek 不招前端。
- 现在的表现：能正确搜到「前端 / 客户端开发工程师」。原因是以前只在官网首页埋的少量岗位里找（DeepSeek 首页只埋了 36 个岗位中的 15 个），现在改成让官方服务器在全部岗位里搜。

**拉全量岗位时大量重复**
- 之前的表现：`job-pro deepseek all` 返回 45 条，其中同一个岗位重复出现 3 次。
- 现在的表现：返回 36 条，一条不重、一条不少。

**看不了完整 JD**
- 之前的表现：`job-pro deepseek detail <岗位id>` 直接报「未实现」，只给你一个网页链接自己去看。
- 现在的表现：直接在终端里返回完整的岗位描述（团队使命、工作职责、岗位要求都有）。

## ⚠️ 注意事项

- 这 7 家公司单次搜索每页最多返回 50 条（官方接口的上限），超过 50 会自动按 50 算。
- 搜索结果里的 `total` 现在是「匹配关键词的岗位总数」，比以前的「全站岗位总数」更准确。
