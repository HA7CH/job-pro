# v1.1.15 更新说明

> 发布日期：2026-07-10

## 这次更新做了什么？

修复了 Chrome 扩展无法稳定收集招聘网站登录会话的问题。

## 修复的问题

之前扩展虽然会尝试读取投递页面发出的登录验证信息，但 Chrome 没有授予它读取请求头的权限。因此，部分网站的授权信息不会被收集，导出的会话文件可能缺少继续投递所需的数据。

现在扩展会明确申请所需权限，在已支持的招聘网站上正常收集登录验证请求中的信息。

## 注意事项

本次没有新增可访问的网站范围。扩展仍只处理 `manifest.json` 中已列出的招聘网站，收集的数据仍只保存在浏览器本地，且只有你点击导出时才会生成文件。
