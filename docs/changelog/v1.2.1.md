# v1.2.1 更新说明

> 发布日期：2026-07-14

## 🎉 这次更新做了什么？

修复 MiniMax 社招岗位链接打开后错误显示“该职位已下线”的问题。

## 🐛 修复的问题

MiniMax 的校招和社招位于两个不同的招聘入口。以前 job-pro 虽然能从社招入口搜到岗位，但生成链接时仍使用校招入口，因此部分真实在招岗位打开后会被页面误报为已经下线。

现在，社招岗位会打开 MiniMax 社招页面，校招和实习岗位仍打开对应的校招页面。搜索结果和岗位详情返回的链接都会自动选择正确入口。

## ⚠️ 注意事项

本次修复只调整岗位链接，不改变搜索结果、岗位描述或匹配排序。
