# v1.2.0 更新说明

> 发布日期：2026-07-11

## 🎉 这次更新做了什么？

job-pro 回归本质：一个把 50 家大厂真实在招岗位拉到你终端里的搜索工具。自动投递（auto-apply）整个功能先下线了，同时我们按 DeepSeek 那次修复的标准，把所有公司的搜索质量重新审计了一遍。

## ⚠️ 移除的功能（Breaking）

**自动投递相关的命令全部下线**：

- `apply`（含 dry-run、--confirm-submit、--batch、--via-cdp 等全部投递流程）
- `profile init` / `profile lint`（投递档案管理）
- `extension`（抓浏览器 session 的 Chrome 扩展）
- `find` 的 `--apply-ready` 筛选和投递就绪图标

为什么去掉？自动投递需要每家公司抓登录 session、维护提交接口格式，实际可用性一直达不到我们要的标准。与其留着一个半吊子功能误导大家，不如先砍掉，把精力放在「搜得全、看得清」上。等它真正可靠了再回来。

**没有变的**：

- 搜索、跨公司 find、看 JD（detail）、简历匹配（match）、简历体检（resume-check）、求职记忆（memory）全部保留。
- `memory event applied` 还在——你手动投递后依然可以记账。
- 简历匹配省略 `--resume` 时依然会读你之前配置的简历路径，不用重新设置。

## 🐛 修复的问题

- 全部 50 家公司按「搜得到、不重复、能看 JD」的标准重新实测过一轮，发现的问题已修复（详见各家的修复说明）。

## ✨ 其他

- `selftest` 改为纯搜索链路自检（搜索 → 看 JD → 简历匹配），不再需要任何投递配置。
- `status` 更简洁：只报告简历档案和求职记忆的状态。
