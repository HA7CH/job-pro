# v1.1.15 开发日志

> 发布日期：2026-07-10

## 修复内容

### Chrome MV3 请求头监听权限缺失

**文件：** `extension/manifest.json`

**根因：** `extension/background.js` 已注册 `chrome.webRequest.onSendHeaders`，并以 `requestHeaders` 和 `extraHeaders` 监听请求头，但 manifest 的 `permissions` 未声明 `webRequest`。Chrome 因而不会向扩展暴露该 API 的请求头事件，服务工作线程会静默退化为仅依赖 cookie 的采集路径。

**修复：** 在 `permissions` 中加入 `webRequest`，并将扩展版本从 `0.1.0` 更新为 `0.1.1`，使已安装的开发者模式扩展能够识别本次权限变更。

**范围：** 未修改 `host_permissions`。监听范围仍受现有招聘网站白名单约束，扩展不会获得额外站点的访问权限。

## 验证

- 使用 Node 解析 `extension/manifest.json`，确认 JSON 合法且 `permissions` 包含 `webRequest`。
- 复查 `extension/background.js` 的 `chrome.webRequest.onSendHeaders` 监听器，确认新增权限与现有调用一一对应。

## 已知问题

- `chrome.tabs` 备用扫描路径尚未在当前扩展源码中实现，因此没有在本次 PR 中增加 `tabs` 权限。待备用扫描代码落地后，应连同最小化权限一起单独评审。
